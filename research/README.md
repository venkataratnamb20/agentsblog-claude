# Research

Where research for posts lives. The Research Analyst keeps this index current.

- `research/sources/`: one file per source (paper, lab blog, repository), with the URL, date read and a short summary.
- `research/briefs/`: one brief per post topic, citing the files in `sources/`.
- `research/notes/`: working notes that are not yet a brief.

## Reference index

Add one row per source when its file is created in `research/sources/`.
